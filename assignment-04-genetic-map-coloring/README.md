# Assignment 4 — Genetic Algorithm for Map Coloring

A Python implementation of a genetic algorithm for the map-coloring constraint-satisfaction problem. Candidate solutions assign one of four colors to each region, while the fitness function rewards assignments in which neighboring regions have different colors.

The program solves both a smaller 10-state instance and a 51-region U.S. map instance.

## Concepts

- Genetic algorithms
- Constraint satisfaction
- Fitness evaluation
- Tournament selection
- One-point crossover
- Mutation
- Elitism
- Reproducible random seeds

## Run

From the `src` directory:

```bash
cd src
python map_coloring.py
```
