# CSC 645 — Artificial Intelligence

Artificial Intelligence coursework and algorithm implementations completed as part of **CSC 645 at the University of Miami**.

This repository contains implementations of fundamental artificial intelligence concepts using **Python and C++**, including intelligent agents, state-space search, heuristic search, constraint satisfaction, and genetic algorithms.

## Projects

### Assignment 1 — Vacuum Agent
**Language:** C++

Implementation of an intelligent vacuum agent interacting with a simulated environment.

Concepts:
- Intelligent agents
- Environment modeling
- Agent decision-making
- C++ implementation

### Assignment 2 — State-Space Search
**Language:** C++

Implementation of state-space search techniques for solving an artificial intelligence search problem.

Concepts:
- State-space representation
- Breadth-first search
- Search trees
- Goal-state detection

### Assignment 3 — Search Algorithms
**Language:** Python

Implementation and comparison of multiple search strategies.

Algorithms:
- Uniform-Cost Search
- Greedy Best-First Search
- A* Search

The project compares solution paths, search costs, and the number of expanded states produced by the different algorithms.

### Assignment 4 — Genetic Algorithm Map Coloring
**Language:** Python

A genetic-algorithm approach to the map-coloring constraint satisfaction problem.

Concepts:
- Genetic algorithms
- Constraint satisfaction
- Population-based search
- Fitness evaluation
- Selection, crossover, and mutation

The implementation was tested on both smaller map instances and a 51-region U.S. map dataset.
