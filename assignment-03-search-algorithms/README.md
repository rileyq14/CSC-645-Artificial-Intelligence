# Assignment 3 — Heuristic Search Algorithms

A Python route-finding program that builds a visibility graph around polygonal obstacles and compares three search strategies: Uniform-Cost Search, Greedy Best-First Search, and A* Search.

## Concepts

- Uniform-Cost Search
- Greedy Best-First Search
- A* Search
- Straight-line-distance heuristic
- Priority queues
- Visibility graphs
- Collision/intersection testing
- Path-cost and node-expansion comparison

## Run

```bash
python src/search_algorithms.py
```

The start point, goal point, and polygon definitions can be changed near the top of the source file to test different environments.
